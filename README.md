# Gestor de Reingreso Estudiantil

Panel de administración y estudiante para la gestión de solicitudes de reingreso de la Universidad de Cartagena.

**Por ahora es lo mínimo:** autenticación, gestión de solicitudes (radicar, cambiar estado, historial), CRUD de usuarios, reportes por período, y log de auditoría. Construido con Next.js 16, Supabase, Clerk, shadcn/ui y Tailwind CSS v4.

```bash
npm run dev
```
